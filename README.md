## Installation

1. Download the preferred theme
2. Open Krita
3. In the menu bar, open the ```Settings/Manage Resources...```
5. Click "Open Resource Folder"
6. Move your file to ```\krita\color-schemes```
7. Open ```Settings/Themes``` and select the theme
